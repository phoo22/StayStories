# StayStories

## サイト概要
### サイトテーマ
宿泊体験や感想を投稿・共有し、旅行者が自分の価値観に合った宿泊先を検討できるレビューサイトです。
​
### テーマを選んだ理由
旅行先で宿泊施設を探す際、選択肢が多く、どの宿泊施設を選べばよいか迷うことがあります。

また、旅行者によって重視するポイントは異なり、価格や一般的な評価だけでは、自分に合った宿泊施設を判断することが難しいと感じています。

特に、静かさや快適さ、アクセスの良さなど、実際に宿泊した人が何を重視し、どのように感じたのかを知ることができれば、宿泊施設選びの参考になると考えました。

そこで、宿泊体験や大切にしている価値観を共有できるレビューサイトを制作しようと考えました。項目ごとの評価や実際の宿泊体験を確認できるようにすることで、旅行者が自分の重視するポイントに合った宿泊施設を見つけやすくすることを目指しています。

### ターゲットユーザ
- 宿泊施設の選択肢が多く、自分に合った宿泊先を選ぶことに迷っている人
- 価格や一般的な評価だけでなく、実際の宿泊体験や他の旅行者の価値観を参考にしたい人
- 自分の宿泊体験や、宿泊先を選ぶ際に重視したポイントを他の旅行者と共有したい人
​
### 主な利用シーン
- 旅行の計画を立てる際に、他の旅行者の宿泊体験や感想を参考にして、自分に合った宿泊施設を探したい時
- 宿泊施設を比較する際に、静かさや快適さ、アクセスの良さなど、自分が重視するポイントについて詳しく知りたい時
- 宿泊後に、自分の宿泊体験や良かった点、気になった点などを写真とともに投稿し、他の旅行者と共有したい時
